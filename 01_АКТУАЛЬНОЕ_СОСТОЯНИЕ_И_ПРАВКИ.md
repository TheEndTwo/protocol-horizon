# АКТУАЛЬНОЕ СОСТОЯНИЕ И ЗАКРЕПЛЁННЫЕ РЕШЕНИЯ — 08.11.2026

## 1. Общее
- Название: «Протокол Горизонт»; Godot 4.7.2 / GDScript, вертикальная мобильная игра 9:16 (контрольный viewport 432×768).
- Исторический пакет v9: три земных участка `site_earth_fe_17`, `site_earth_pd_7`, `site_earth_ir_9`; 140 технологий, 24 навыка мастерства, 80 коллекционных специалистов и 20 сюжетных сцен. Считать это ПЛАНОМ, а не автоматически существующими системами.
- Железная шахта №17: предусмотрены 10 улучшений, 8 слотов экипировки, 5 типов машин, 5 профессий; числовые границы уровней уточняются по действующим данным. Горизонты открываются по существующим правилам прогрессии, исторический ориентир — каждые 100 агрегированных уровней, но не надо создавать новые правила без проверки кода.
- **Сезонный пропуск = 60 уровней.** Упоминания 40 в v9 устарели. Решение владельца уже принято и, по его словам, в игре корректировалось. Проверка реального кода — только при будущем изменении сезона, НЕ в текущей задаче.
- **Игровой XP персонажа не определять по сезону.** Это отдельная система. Прежние данные старого прототипа про достижения/+10 XP/ранги не переносить без отдельного согласования.

## 2. Этап 1 — главная промышленная база
По оценке владельца внешний вид утверждён; текущая работа не должна её затрагивать. Премиальный индустриальный ландшафт, горы, постройки, интерактивные названия зданий, верхний HUD и нижнее меню. **Нет и не должно быть большой круглой кнопки ручной добычи на базе.** Ручная добыча только внутри шахты.
- Одна отмеченная ранее неудачная анимация БелАЗа (ехал боком вне дороги) подлежала отключению; в текущем задании об этом не просили. Не возвращай её и не переписывай базу.

## 3. Этап 2 — главный экран шахты №17
Владелец прислал два последних скриншота 08.11 и объявил этот этап завершённым по внешнему виду. Видно: компактная верхняя строка **только с тремя валютами**, большая рабочая сцена с рудой/шахтёрами, показатели добычи, шкала прогресса, кнопка **«Продать железо»**, горизонтальные карточки геологических горизонтов, нижние вкладки «Улучшения», «Оборудование», «Машины», «Рабочие».
- На экране шахты специально **убраны** логотип/большой заголовок, VIP, профиль, XP, уведомления, почта и настройки. НЕ восстанавливать их.
- Принята большая зона ручной добычи с возможностью быстрых и множественных касаний. Удары шахтёров в фоне НЕ должны синхронизироваться с тапами. Анимации рабочих — прицельные удары в породу, адекватная перспектива, умеренные искры/крошка. Пользователь сказал, что нынешняя сцена его устраивает: НЕ переделывать.
- Стартовая техника/люди должны соответствовать покупкам/назначениям. Фоновые декоративные персонажи не дают автоматического дохода без покупки. Тяжёлая техника появляется только при фактическом приобретении.
- Ранее существовала автопродажа в другом месте игры, а на экране шахты сейчас есть кнопка «Продать железо». Не создавать вторую экономическую систему продажи.

### Маленький остаток по экрану шахты
Кнопка **«Улучшить шахту»** ведёт туда же, куда нижняя вкладка **«Улучшения»**, и дублирует её. Владелец хочет удалить только эту дублирующую кнопку, **оставив прогресс-бар уровня**. Можно сделать вместе с задачей вкладки улучшений, не трогая остальную шахту.

## 4. Текущий этап 3 — «Улучшения шахты»
НЕ завершён. В архиве есть последняя УТВЕРЖДЁННАЯ ХУДОЖЕСТВЕННАЯ КОМПОЗИЦИЯ (компактная, числовые значения внутри карточек, без выпирающих рамок). Действующий скриншот до переделки включён отдельно для сравнения.
- При переносе эталона на UI **верхняя часть только из трёх валют**, без логотипа, профиля, VIP, почты, уведомлений, настроек; художник на картинке мог оставить логотип, но более позднее решение важнее.
- У карточки улучшения нужны РЕАЛЬНЫЕ «сейчас → после следующего уровня» с ПРАВИЛЬНЫМИ единицами: например 10→12 железа/удар, или 12%→14% для вероятности критического удара, или 0,02→0,03 железа/сек, если так реально считает игра. НЕ все бонусы переводить в проценты.
- Кнопки цены — **целое число и иконка Гелионов**, без дробей `219,60` и без буквенного «Г»; отображение и фактическое списание должны совпадать. Конкретная политика округления должна использовать один источник расчёта и не повреждать остальную экономику.
- Краткие горизонтальные прямоугольники в нижней навигации, не квадраты; «Машины» — иконка шахтного самосвала, НЕ строительного крана.
- 10 карточек в двух колонках, вертикальная прокрутка нужного контента, не обрезать/не перекрывать, сохранить существующие системы.
- Не менять остальные три вкладки до их отдельных этапов.

## 5. Визуальное правило
Тёмно-синий/графитовый металл + сдержанный золотой свет, высокая читаемость русских подписей. Новые изображения — отдельные ассеты при необходимости, но не статичная картинка с поддельными кнопками. Сценарии прогрессии должны быть связаны с реальными покупками/значениями. Динамические игровые цифры — Godot UI, не запекать в PNG.
