## Карточки: содержимое и состояние
Для КАЖДОЙ из 10 существующих улучшений:
- подходящая тематическая иконка/арт;
- ТОЧНОЕ текущее название из данных игры (русский язык), краткое описание;
- реальный текущий уровень;
- понятная характеристика до и после ОДНОЙ следующей покупки с единицами;
- стоимость следующей покупки: небольшая общая иконка монеты Гелионов + **целое число** без «Г» и без дробей;
- интерактивная кнопка оплаты с корректными состояниями: можно купить, не хватает валюты, достигнут максимум;
- после покупки одновременно обновляются валюта, уровень карточки, результат «сейчас → после», цена следующего уровня, и реальные производственные показатели.

### «Сейчас → Следующий уровень» — основной смысл экрана
Не механически показывать одинаковый процент везде. Выбирай единицу по фактической формуле каждого улучшения:
- ручная добыча: например `10 → 12 железа/удар`;
- критический шанс: например `12% → 14%`;
- производство: например `0,02 → 0,03 железа/сек`;
- вместимость/количество сотрудников: целое количество, только если влияет именно на него;
- скорость загрузки: реальные единицы (например `руды/сек`, либо `+X%`), соответствующие существующему эффекту;
- остальные эффекты — соответствующие им единицы.
Цифры примеров — не для хардкода. До покупки вычисляй теоретическое «после» тем же расчётчиком, что будет применён при покупке, включая другие действующие бонусы. Следующее изменение должно быть достоверным и объяснимым.

### Цены
Прежние дробные цены вроде `219,60 Г`, `130,69 Г`, `143,78 Г` заменить целыми с иконкой: `220`, `131`, `144` соответственно по согласованному округлению. Прежде чем менять расчёт, смотри, где именно формируется фактическая цена и происходит списание. Обеспечь, чтобы UI и дебет были ОДНИМ числом. Не исправляй произвольно глобальные коэффициенты экономики. Если в текущих данных дроби несут значимую игровую механику, минимально нормализуй цену в общем для этого улучшения месте с сохранением совместимости, либо сообщи о противоречии вместо маскировки дроби только текстом.
