# Запуск Protocol Horizon GPT-6.1

Нужен Godot **4.7.2 stable**. Лаунчер не скачивает движок и не предполагает его путь на Mac: он проверяет `GODOT_BIN`, затем `godot`/`godot4` в `PATH`, а на macOS — приложение Godot, найденное Spotlight по bundle ID `org.godotengine.godot`.

## Запуск из корня репозитория

```bash
bash ProtocolHorizonGPT61/tools/run_macos.command
```

Если Godot не найден автоматически, укажите фактический путь к исполняемому файлу, установленный на вашем Mac:

```bash
GODOT_BIN="<фактический путь к исполняемому файлу Godot 4.7.2>" bash ProtocolHorizonGPT61/tools/run_macos.command
```

Вместо Terminal можно открыть Godot, выбрать **Import**, указать `ProtocolHorizonGPT61/project.godot` и запустить проект из редактора.

## Проверки в текущей Linux-среде разработки

Установленный здесь Godot 4.7.2 stable находится по пути `/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64`. Команды ниже относятся к этой среде; на другой машине используйте её фактический путь к Godot.

Импорт проекта в headless-режиме:

```bash
/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64 --headless --path ProtocolHorizonGPT61 --editor --import
```

Stage 0 тест:

```bash
/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64 --headless --path ProtocolHorizonGPT61 --script res://tests/stage0_test.gd
```

Графический запуск проекта в текущей Linux-среде (здесь уже работает Xvfb на `:99`):

```bash
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 /tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64 --path ProtocolHorizonGPT61 --position 0,0 --resolution 432x768 --audio-driver Dummy
```

## Проверка этапа 1 на Mac

1. Импортируйте `ProtocolHorizonGPT61/project.godot` в Godot 4.7.2 и запустите либо используйте лаунчер выше. Заставка сразу открывает меню: **Новая игра / Продолжить / Настройки**. Учётная запись не нужна.
2. На чистом профиле **Продолжить** недоступно. Сохранение одних настроек не создаёт игровой профиль.
3. В настройках измените громкость (слышен предпросмотр), FPS, качество или уменьшение анимации; нажмите **Сохранить настройки**. «Назад без изменений» отменяет только несохранённые изменения. Настройки прокручиваются, кнопка сохранения остаётся доступна.
4. **Новая игра** создаёт отдельный профиль и открывает A01 из канона. Нажмите **Далее**, выйдите в меню, закройте приложение и снова запустите. **Продолжить** возвращает к той же реплике. **Пропустить вступление** сохраняет переход к экрану окончания этапа 1; наград нет.
5. При наличии профиля **Новая игра** требует подтверждения. **Отмена** не меняет прогресс, подтверждение создаёт новый профиль, но сохраняет настройки.

## Сохранения и границы этапа

Формат **schema_version 1**, путь `user://protocol_horizon_gpt61_save_v1.json`, резервная копия с суффиксом `.bak`; отдельная папка user-dir **ProtocolHorizonGPT61**. Фактическую папку можно открыть через Godot **Project → Open User Data Folder**. Чужие и старые сохранения не читаются и не мигрируются.

Запись идёт во временный файл с последующим атомарным переименованием; повреждённый основной файл восстанавливается из корректного бэкапа, а неизвестная версия не переписывается настройками. Ошибки записи видны пользователю. Сохранения пользователя не входят в git.

Начало игры: Fe открыт, Pd/Ir закрыты, гелионы/железо/осколки/ОИ равны нулю. Неутверждённые XP, снаряжение, бонусы и сюжетные награды не выдуманы. A01 здесь — только вступление, не выполнение условий первого удара. Экран после него честно отмечает конец этапа 1: **база и добыча не реализованы**, этапы 2–19 не начаты.

Master/Music/SFX/Ambience управляют отдельными аудиошинами; музыка и фоновый трек ещё не добавлены. Качество переключает разрешение фоновой текстуры; энергосбережение не обещает замеренную экономию батареи. Ограничение 30/60 FPS действительно применяется, reduced motion отключает появление фона. Вибрация вызывается только на мобильной платформе; аппаратно не проверена.

Меню использует отдельную фотографию карьера и новые текстурные рамки, не референс-скриншот с нарисованными кнопками. **Арт временный**: нет инструмента генерации иллюстраций, финальный оригинальный промышленный арт остаётся на согласование. Источник и права — `assets/ART_CREDITS.md`. macOS и физический iPhone недоступны и не проверялись.

## Изолированная автоматическая проверка

Из корня репозитория; Godot в этой Linux-среде — по пути выше. Не направляйте тесты в папку своих сохранений.

```bash
GODOT=/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64
TEST_ROOT="$(mktemp -d)"
export XDG_DATA_HOME="$TEST_ROOT/data" HORIZON_TEST_ISOLATED=1
"$GODOT" --headless --path ProtocolHorizonGPT61 --script tests/stage0_test.gd
"$GODOT" --headless --path ProtocolHorizonGPT61 --script tests/stage1_test.gd
"$GODOT" --headless --path ProtocolHorizonGPT61 --script tests/stage1_test.gd -- --reload
XDG_DATA_HOME="$TEST_ROOT/save-cases" "$GODOT" --headless --path ProtocolHorizonGPT61 --script tests/save_service_test.gd
```

Тест `stage0_test.gd` сохраняет проверки каталогов/ID и обновлён для немедленного открытия меню этапа 1 вместо удалённого технического перехода «К меню / Назад». Тест `stage1_test.gd` проверяет реальные UI-сигналы, сохранение настроек и диалога, подтверждение сброса и отдельный повторный процесс. Проверка файловой надёжности — `tests/save_service_test.gd`.
