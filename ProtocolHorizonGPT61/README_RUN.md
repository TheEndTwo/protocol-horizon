# Запуск Protocol Horizon GPT-6.1

Нужен Godot **4.7.2 stable**. Лаунчер не скачивает движок и не предполагает его путь на Mac: он проверяет `GODOT_BIN`, затем `godot`/`godot4` в `PATH`, а на macOS — приложение Godot, найденное Spotlight по bundle ID `org.godotengine.godot`.

## Запуск из корня репозитория

```bash
bash ProtocolHorizonGPT61/tools/run_macos.command
```

Если Godot не найден автоматически, укажите фактический путь к исполняемому файлу, установленный на вашем Mac:

```bash
GODOT_BIN="<фактический путь к исполняемому файлу Godot 4.7.2>" bash ProtocolHorizonGPT61/tools/run_macos.command
```

Вместо Terminal можно открыть Godot, выбрать **Import**, указать `ProtocolHorizonGPT61/project.godot` и запустить проект из редактора.

## Проверки в текущей Linux-среде разработки

Установленный здесь Godot 4.7.2 stable находится по пути `/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64`. Команды ниже относятся к этой среде; на другой машине используйте её фактический путь к Godot.

Импорт проекта в headless-режиме:

```bash
/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64 --headless --path ProtocolHorizonGPT61 --editor --import
```

Stage 0 тест:

```bash
/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64 --headless --path ProtocolHorizonGPT61 --script res://tests/stage0_test.gd
```

Графический запуск проекта в текущей Linux-среде (здесь уже работает Xvfb на `:99`):

```bash
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 /tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64 --path ProtocolHorizonGPT61 --position 0,0 --resolution 432x768 --audio-driver Dummy
```

## Как начать игру

1. Запустите **Новая игра**, пройдите или пропустите A01. После вступления открывается база, а не прежняя заглушка окончания этапа 1.
2. Нажмите **В шахту №17** или здание шахты. Удары по породе бесплатны даже при 0 Г. Продайте свободное железо, откройте **Улучшения**, купите первый уровень; далее машины и работники.
3. Через список разделов сверху доступны производство, склад, контракты, геология, исследования, мастерство, сюжет, коллекции, сезон и карта Земли. Кнопка **↻** обновляет текущий список без перехода в другой раздел.
4. Реальные цели сюжета показаны в **Сюжет / архив**. Pd и Ir открываются по игровым условиям; появление карточки на карте не означает доступность участка. Продажа руды не требует завода.
5. Перед заменой существующего профиля требуется подтверждение. «Продолжить» возвращает на сохранённую страницу; настройки и прогресс записываются отдельно от внешнего оформления.

## Сохранения

Формат **schema_version 1**, имя `user://protocol_horizon_gpt61_save_v1.json`, резервная копия `.bak`, отдельный user-dir **ProtocolHorizonGPT61**. Старые сохранения других проектов не читаются. Фактическую папку можно открыть в Godot через **Project → Open User Data Folder**.

Запись временного файла с flush и атомарным переименованием; только валидный предыдущий файл попадает в backup. Повреждённый основной файл можно восстановить из `.bak`; неизвестная будущая версия не переписывается настройками. При ошибке записи транзакция не выдаёт покупки/награды. Автосохранение сохраняет пассивную симуляцию; действия сохраняются сразу.

Офлайн обрабатывает те же производственные системы, зарплаты и резервы. Время ограничено текущим лимитом 4–24 часа, движение часов назад не даёт отрицательного времени. Отчёт показывает уже учтённый результат, а не кнопку повторного начисления.

## Текстуры и баланс

Последним решением владельца промежуточные согласования отменены, **текстуры владелец добавит позднее**. Отдельные SVG-заготовки не выдаются за финальный референсный арт. Порядок замены через `data/art_overrides.json` — **`docs/TEXTURE_GUIDE.md`**. Числа/кнопки — реальные Godot UI; текстуры не должны содержать динамические значения.

`data/canon/` и исходный архив неизменны. Отсутствующие в каноне формулы, длительности, идентификаторы улучшений и награды вынесены в **`data/proposals/`**, явно предварительные. Это рабочий баланс прототипа, не утверждённый коммерческий баланс. Реальные StoreKit/IAP/реклама без SDK отключены: фиктивных покупок и VIP-начислений нет.

Master/Music/SFX/Ambience, 30/60 FPS, reduced motion и качество применяются к работающему приложению. Музыкальный трек пока не добавлен; фон конвейера и эффекты используют прототипные WAV. Mac, аппаратное звучание/вибрация и физический iPhone здесь не проверены; замеры 60 FPS на iPhone не заявляются.

## Проверки Linux без изменения своих сейвов

```bash
GODOT_BIN=/tmp/horizon-tools/Godot_v4.7.2-stable_linux.x86_64 bash ProtocolHorizonGPT61/tools/test_game.sh
```

Скрипт создаёт временную папку user-data, выполняет импорт, тесты моделей, повторный запуск и файловые проверки. Он отклоняет `SCRIPT ERROR` в журнале даже при exit code 0 от Godot. Fixture-прогресс тестов не включён в новую игру.

Результаты и реально оставшиеся ограничения — **`DEVELOPMENT_PROGRESS.md`**, баланс — **`docs/BALANCE_RESULTS.md`**.

## Готовые пакеты и повторный экспорт

В `builds/` формируются `ProtocolHorizon-macOS.zip` (приложение macOS, без подписи/нотарификации), `ProtocolHorizon.x86_64` (Linux) и `ProtocolHorizonGPT61-source.zip` (редактируемый Godot-проект). Сохранения и тестовые профили в архивы не включаются. Для добавления своих текстур используйте исходный проект, а не внутренности экспортированного приложения.

После установки export templates именно для Godot 4.7.2:

```bash
bash ProtocolHorizonGPT61/tools/run_macos.command --headless --editor --export-release "macOS Test"
bash ProtocolHorizonGPT61/tools/run_macos.command --headless --editor --export-release "Linux Test"
```

Полный проверочный прогон также включает `earth_story_test.gd -- --f2p`: путь до A20 с реальными заработком и производством, без стартовых грантов. Ускоренные модельные часы не равны сроку прохождения при редких входах.
