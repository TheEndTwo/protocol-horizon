# ЧИСТАЯ АРХИТЕКТУРА GODOT 4.7.2

**Новый проект.** Работай в отдельном каталоге `ProtocolHorizonNew` — никакого обновления `ProtocolHorizon` старой игры, никаких импортов `main.tscn`/`main.gd`/`user://` от неё. Save schema **v1 нового проекта** и новый `user://horizon_new_save_v1.json`, резервная атомарная запись. Можно копировать только идеи/каталоги данных из приложенного пакета; если старый код вдруг доступен, не встраивай его без отдельного явного разрешения пользователя. `project.godot` создаёт Codex, в этом архиве исходный Godot-проект не включён.

  scenes/start/       Splash.tscn  MainMenu.tscn  Settings.tscn

Ключевые data-driven интерфейсы: `SiteDefinition`, `UpgradeDefinition`, `EquipmentDefinition`, `MachineDefinition`, `WorkerDefinition`, `RecipeDefinition`, `ResearchNode`, `MasteryNode`, `SpecialistDefinition`, `StoryEvent`, `UnlockRule`, `CasePool`, `RewardTransaction`, `WorldLocation`, `PrestigeRule`, `SeasonTask`. Три сценария добычи = разные стратегии `iron_tap`, `palladium_lens`, `iridium_campaign` с общим ledger; **не** три копии Fe UI. Технические ID с каталогов неизменны; русские наименования ресурсов, английские имена персонажей в локализованных строках, `ui_ru_RU` начальный.

Сохраняемые данные: версия схемы; все глобальные валюты и материалы; `lifetime_peak` и локальная текущая прокачка для каждого site; деньги/зарплаты; складские/контрактные резервы; пассивные конвейеры/кампании с seed и time; исследовательские уровни/ОИ; мастерство; список owned_specialists, уровни и звёзды, назначения; экипировка; сезонные задания/наградные `claim_id`; VIP-очки/ранги/квитанции; кейсные гарантии и результат транзакции; `story_flags` и `phase2_discovered`, `tutorial_progress`, settings; timestamp/capped offline + `offline_claim_id`.

**Атомарная экономика:** любая покупка/отгрузка/престиж/награда проходит `validate → reserve → commit → save`, нельзя выдавать награду только по анимации. Сохранения должны переживать закрытие приложения между началом и концом анимации кейса; незавершённые операции идемпотентны. Платежи только подтверждённые StoreKit receipts с дедупликацией `transaction_id`, не рандомный debug-flag. Нет сети → игра не падает, обычное F2P продолжает работать, store OFF.

**Оффлайн:** при возврате `effective_seconds = min(max(now-last_saved_ts,0),offline_cap_seconds)`, симулировать все предприятия и завод единым порядком с учётом денег, входов рецептов, зарплат, резервов, кампаний и текущих лимитов. Сохранить новый claim-ID в той же операции; повторный показ отчёта не начисляет деньги. Смена FPS/вкладок не влияет на выпуск.

**Зависимости:** граф технологий — DAG; сюжетные триггеры не зависят от сбросов и платных опций; `story:A07` факультативен и не может быть `A08` prerequisite; `A14`/`A20` без `iron_lifetime_700`/`900`. Научные ID `A01` не путать с `story:A01`, использовать отдельные пространства имён.
